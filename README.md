CNN2FPGA

Authors: Flipe Puente, Juan Martín Sánchez

This repository contains code to train a 2D VoxelMorph model in TensorFlow, quantize, and compile it for the AMD Kria KV260 DPU, and the appropiate host code to deploy the model on the KV260 FPGA board using Xilinx/Vitis AI 3.5 toolchains.

The dataset can be downloaded from: https://drive.google.com/file/d/1ZCS6p5TXkmNj6QnDuiTPBap8KoZkxl9G/view?usp=drive_link
